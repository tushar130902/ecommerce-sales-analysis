
# Dataset Instructions

1. Download the Online Retail dataset from:

https://archive.ics.uci.edu/dataset/352/online+retail

2. Extract the downloaded file.

3. Open Online Retail.xlsx in Excel.

4. Save the worksheet as CSV UTF-8.

5. Name the file Online_Retail.csv.

6. Import the CSV into the raw staging table
   using the instructions in the project.

The original dataset is not included in this repository.
